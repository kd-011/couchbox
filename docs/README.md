# Games docs

Index of this repo's documentation. Every doc in this folder is linked here, one line each.

- [AGENTS.md](../AGENTS.md): commands, conventions and traps for coding agents (CLAUDE.md imports it). Private: the public export leaves it out.
- [PRD.md](PRD.md): what it is for, who uses it, features and their state.
- [ARCHITECTURE.md](ARCHITECTURE.md): components, data flow, storage, auth, external services.
- [DECISIONS.md](DECISIONS.md): dated record of why it is built the way it is.
- [DESIGN.md](../DESIGN.md): how it looks: device, direction, identity, system, refusals.
- [brand.md](brand.md): who it speaks as: name, voice, copy bank, assets, contact and legal.
- [GAME-MODULES.md](GAME-MODULES.md): the game module contract, how one folder in `games/` becomes a game in every mode and tier.
- [HOSTBOX-PROTOCOL.md](HOSTBOX-PROTOCOL.md): the server side of the Host Box hardware protocol: pairing, scenes, button presses.
- [SELF-HOSTING.md](SELF-HOSTING.md): running your own copy on a home network, with Docker or on the internet, and every setting.
- [TELEMETRY.md](TELEMETRY.md): the `[rooms]` journal lines and the `npm run plays` summary.
- [screenshots/](screenshots/): README screenshots and the gameplay GIF, made by `scripts/screenshots.mjs` and `scripts/demo-gif.mjs`.
- [Project dossier](../dossiers/games.md): the short pinned claim list that the public repo's weekly upkeep checks.
